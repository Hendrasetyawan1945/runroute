# Issue 05: Interactive Elevation Profile Chart

Status: resolved
Type: task

## Goal
Build sleek interactive SVG elevation profile chart docked at the bottom of the screen.

## Requirements
- Render smooth gradient area chart of elevation vs distance.
- Display Min/Max elevation labels, current gradient, Gain (+m) & Loss (-m).
- Interactive hover: moving mouse over chart highlights corresponding distance, elevation, and communicates hover coordinate to the map to display a live runner dot.
- Collapse / Expand toggle button to give runners maximum map space when desired.
